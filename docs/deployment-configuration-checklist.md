# 「由迹而寻」发布配置核对

## 已配置

- 微信小程序 AppID 已写入 `src/manifest.json` 的 `mp-weixin.appid`。
- 微信开发者工具域名校验已开启，避免开发环境掩盖生产域名问题。
- 微信构建已启用压缩和分包优化。
- `.gitignore` 已排除 `.env`、PEM/PPK 和常见 SSH 私钥文件，防止运行密钥进入版本库。
- 顶层 DCloud `appid` 保持为空；它不是微信 AppID，当前微信 CLI 构建不需要用微信 AppID 代填。
- 可提交的公开生产配置已写入 `.env.production`：`https://api.asyore.cn/fitness-api/v1`。该前缀用于避开服务器上现有 Java 服务占用的根路由。
- API 运行时配置入口已建立在 `src/config/runtime.ts`，只读取公开的基础地址和超时配置。
- `api.asyore.cn` HTTPS 证书和外部访问已验证通过。
- Node.js 20 后端已部署至 `/home/ubuntu/asyore-server`，由 PM2 管理并设置开机自启。
- `/fitness-api/` 已通过 Nginx 转发到 `127.0.0.1:3000`，现有 8080 Java 服务保持不变。
- MongoDB 8 已启用鉴权；管理用户与 `asyore_db` 最小权限应用用户已分离，应用 `.env` 权限为 `600`。
- 微信登录、JWT 访问/刷新令牌、训练同步、幂等打卡、导出和账号删除接口已部署。
- 前端“我的”页已提供云端备份明确授权、手动同步、关闭备份和删除云端数据入口；默认仍为本地存储。
- H5 与微信小程序构建已通过；微信包体总计 2.68 MB，并已移除构建运行时的未声明远端阴影图片请求。

## 安全整改

当前外部 Markdown 文档保存了多类明文密钥和密码。建议立即：

1. 迁移到服务器 `.env` 或云密钥管理服务，并设置仅服务账号可读。
2. 轮换微信 AppSecret、服务器密码、数据库密码、COS 密钥和 JWT 密钥。
3. 删除 Markdown 中的明文值，只保留变量名、用途和密钥存放位置。
4. 检查该文档是否进入过网盘、Git、聊天或历史备份；若进入过，按已泄露处理。
